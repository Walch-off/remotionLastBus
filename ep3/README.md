# «Последний автобус» — Часть 3 (исходник)

Анимированный вертикальный эпизод (1080×1920, 30 fps, H.264, 153.469 с) к серии
«Последний автобус». Полностью процедурная 2D-анимация: каждый кадр — чистая
функция от времени, отрисованная в SVG и растеризованная `resvg`, затем собранная
`ffmpeg`. Remotion/Chrome не используются (в среде нет браузера), поэтому рендер
идёт без headless-браузера.

## Что внутри

```
src3/
  theme.ts            палитра, FPS/размеры кадра, easing, ramp/keyframe, шум
  engine/             мини JSX→SVG рантайм (h, Fragment, renderToString, svgDoc)
  shots.ts            монтажный лист: 14 отрезков, камера, тайминги
  subtitles.ts        нарезка субтитров (≤5 слов / ≤22 символа / пунктуация)
  data/words3.json    пословное выравнивание озвучки (57 фраз, 261 слово)
  scene/
    Hero.tsx          риг персонажа: Hero, Double, HeadOnly, Hand, Arm, Eye, Mouth
    Bus.tsx           салон автобуса: перспектива, окна, сиденья, лампы, поручни
    Street.tsx        ночная улица: дома, дорога, фонарь, остановка, дождь
    Marks.tsx         отпечатки ладоней, потёки, надпись на стекле, пар дыхания
  scenes/
    Bus.tsx           все сцены эпизода + диспетчер BusScene
    Street.tsx        внешние кадры (через стекло), двойник на остановке
    Overlays.tsx      карточки голосования, заголовок, субтитры
  Timeline.tsx        сборка кадра: камера + сцена + субтитры
  render-entry.tsx    экспорт frameAt(t) для рендера
scripts/
  script3.txt         текст озвучки (как записан в WAV)
  align3.py           выравнивание текста по WAV без ASR → src3/data/words3.json
  mix3.py             синтез SFX + атмосферы и микс с голосом → public/audio3/mix.wav
  render.mjs          рендер кадров/видео
  filmstrip.mjs       контактный лист для быстрой проверки
  scan.mjs            прогон всех кадров в дочерних процессах (защита от падений resvg)
public/audio3/
  voice3_original.wav копия исходной озвучки (не изменялась)
  mix.wav             итоговый микс (голос 1.0 / атмосфера 0.10 / SFX 0.4);
                      не в git — собирается заново: python3 scripts/mix3.py
assets/hero.png       копия исходного референса персонажа
```

## Запуск

```bash
npm ci                       # зависимости: @resvg/resvg-js, esbuild, @ffmpeg-installer/ffmpeg
python3 scripts/align3.py    # (опционально) пересчитать тайминги слов по WAV
python3 scripts/mix3.py      # (опционально) пересобрать звук (нужны numpy, scipy)
node scripts/render.mjs --stills 5,64.6        # контрольные кадры → out/stills/
node scripts/render.mjs --video --out render/video.mp4  # полный рендер (~20 мин)
```

Готовый файл: `render/video.mp4` (1080×1920, 30 fps, 2:33). Архив исходников: `render/part3-source.zip`.

Зависимости: Node 22, Python 3.11 (numpy, scipy), шрифты DejaVu Sans
(`/usr/share/fonts/truetype/dejavu/`).

## Сцены (по монтажному листу)

1. 0.0–7.4 — голосование «ОСТАТЬСЯ В АВТОБУСЕ», герой в салоне, мокрые отпечатки на плечах
2. 7.4–13.6 — двери закрываются, автобус трогается
3. 13.6–21.8 — пустые остановки проплывают за стеклом
4. 21.8–32.6 — водитель смотрит только в зеркало
5. 32.6–37.9 — «в зеркале не ты», фонарь гаснет
6. 37.9–46.6 — автобус возвращается к той же остановке (вид через мокрое стекло)
7. 46.6–61.0 — герой выходит, двойник у остановки улыбается
8. 61.0–66.2 — три пальца → два → один
9. 66.2–83.6 — свет гаснет, мокрые шаги, фонарик, рука на поручне
10. 83.6–90.3 — отражение в зеркале поднимает руку
11. 90.3–101.0 — на стекле проступает «НЕ ОТВЕЧАЙ ЕМУ»
12. 101.0–113.5 — «Если ты настоящий, скажи, как тебя зовут»
13. 113.5–123.3 — автобус встал, двойник стучит по стеклу одним пальцем
14. 123.3–139.9 — улыбка в зеркале против лица без улыбки, водитель кладёт ключ
15. 139.9–153.469 — герой между зеркалом и ключом, финальное голосование

Герой нигде не выбирает за зрителя: в финале он только стоит между зеркалом и
ключом, все три варианта висят в карточке голосования.
