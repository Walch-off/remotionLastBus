# «Последний автобус» — Remotion-проект (часть 4)

Вертикальное видео 1080×1920, 30 fps, H.264. Композиция части 4 — `LastBusPart4`
(также в проекте остаются `LastBusPart1…3`).

## Запуск

```bash
npm install
npm run studio                      # предпросмотр в Remotion Studio
npm run render:ep4                  # → out/last-bus-part4.mp4
npx remotion render src/index.ts LastBusPart4Test out/test.mp4   # 10-секундный тест удара по зеркалу
```

Нужен Node 18+. Если в системе нет Chromium из `remotion.config.ts`, Remotion скачает свой headless-браузер
(путь можно задать переменной `REMOTION_CHROME`).

## Звук и тайминги (часть 4)

Исходная озвучка лежит без изменений в `public/audio4/voice_original.wav`.
Всё, что зависит от неё, пересобирается двумя скриптами (Python 3 + `numpy scipy`; для распознавания — `faster-whisper`):

```bash
python scripts/align4.py          # слова сценария (scripts/ep4_script.txt) ↔ таймкоды Whisper (src/data/asr4_raw.json)
python scripts/build_audio4.py public/audio4/voice_original.wav
```

`build_audio4.py` вставляет 4 короткие паузы в настоящую тишину между фразами (0.75 с перед «Стекло треснуло»,
0.6 с перед стуком, 0.35 с после «…выпустил меня», 0.5 с после шипения дверей) и 3.2 с финального экрана,
пишет `src/data/words4.json` (слова с таймкодами после монтажа), `src/data/cues4.json` (события для анимации и звука)
и дорожки `public/audio4/{voice_final,sfx,ambience,music}.wav`. Все эффекты синтезированы программно в этом скрипте.

## Где что лежит

- `src/ep4/state4.ts` — лист преемственности: кто где стоит и что держит в каждый момент (молоток, ключ, телефон,
  состояние зеркала, следы, свет, двери). Все планы берут состояние отсюда.
- `src/ep4/Set4.tsx` — салон у кабины (общий вид), зеркало, вид за окном, двойник.
- `src/ep4/Scenes4.tsx` — отдельные крупные планы: проход, окно, пол, телефон.
- `src/ep4/props4.tsx` — молоток, ключ, телефон в кулаке, мокрая ладонь, трещины, отпечатки.
- `src/ep4/Episode4.tsx` — раскадровка (границы планов по словам озвучки), надписи, субтитры, звук.
- `src/components/Hero.tsx` — персонаж (общий для всех серий; добавлены предметы в кулаке, крик, обратная кинематика рук).

## Примечание об архиве предыдущих серий

Архив `last-bus-remotion-project.zip` в репозитории обрезан (нет центрального каталога, файл кончается на 95 223 808 байтах).
Из него восстановлены исходники и звук частей 1–3, но `package.json`, `tsconfig.json` и картинки `public/parts/*.png` потеряны —
`package.json`/`tsconfig.json` созданы заново. Дорожки частей 1–3 (`public/audio`, `audio2`, `audio3`) в этот архив не включены
из-за размера; для рендера частей 1–3 их нужно положить из исходного архива (у части 1 `music.wav` в исходном архиве повреждена).
