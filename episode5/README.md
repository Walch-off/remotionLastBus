# «Последний автобус» — Remotion-проект (часть 5)

Вертикальное видео 1080×1920, 30 fps, H.264 + AAC. Композиция части 5 — `LastBusPart5`
(тест сложного места — `LastBusPart5Test`: ключ в замке и фигура в зеркале).

## Запуск

```bash
npm install
npm run studio                      # предпросмотр в Remotion Studio
npm run render:ep5                  # → out/last-bus-part5.mp4
npx remotion render src/index.ts LastBusPart5Test out/test5.mp4
```

Нужен Node 18+. Если Chromium из `remotion.config.ts` не найден, Remotion скачает свой headless-браузер
(путь можно задать переменной `REMOTION_CHROME`).

## Озвучка, музыка и эффекты

Исходная озвучка лежит без изменений в `public/audio5/voice_original.wav`. Всё остальное пересобирается так
(Python 3 + `numpy scipy`; для распознавания — `faster-whisper`):

```bash
python scripts/align5.py                                   # текст сценария ↔ таймкоды слов Whisper (src/data/asr5_raw.json)
python scripts/build_audio5.py public/audio5/voice_original.wav
```

`build_audio5.py`:
- вставляет 4 короткие паузы в тишину между фразами на раскрытиях (0.55 с после «кто-то шёл», 0.45 с после «Ничего»,
  0.35 с после «стучала по стеклу», 0.65 с после «автобуса уже не было») и 3.8 с финального экрана;
- пишет `src/data/words5.json` (слова после монтажа) и `src/data/cues5.json` (события для анимации и звука);
- синтезирует музыку (ре минор: пэд, музыкальная шкатулка, пульс, тремоло, гул — уровни меняются по сценам,
  музыка уходит в тишину на раскрытиях), эффекты и атмосферу дождя, сводит их тише голоса с приглушением под речью.
  Сторонних треков и библиотек звуков нет.

## Где что лежит (часть 5)

- `src/ep5/state5.ts` — лист преемственности: где герой, водитель, двойник, ключ, телефон, двери, ладонь, фигура в зеркале.
- `src/ep5/Set5.tsx` — салон: зеркало с отражением прохода и фигурой, дверь с замком, вид за окном с двойником.
- `src/ep5/Ext5.tsx` — остановка снаружи: борт автобуса, дверь и замок снаружи, фонарь, герой и водитель.
- `src/ep5/Scenes5.tsx` — крупные планы: проход, замок, телефон, ноги на асфальте, рамка двери.
- `src/ep5/props5.tsx` — призрачная ладонь на предплечье, фигура из зеркала, замок с ключом.
- `src/ep5/Episode5.tsx` — раскадровка, надписи, субтитры, звук.
- `src/components/Hero.tsx` — персонаж; для части 5 добавлены карман, в который прячется ключ, и собственное лицо водителя.

Части 1–4 остаются в проекте как исходники; их звуковые дорожки в этот архив не входят (см. папку `episode4` и исходный архив).
Исходный архив `last-bus-remotion-project.zip` в репозитории обрезан; проект собран из восстановленных из него файлов.
